# P2 Requirement Trace — Feasibility & Impact Intelligence

This matrix separates the user's phase-execution request from the P2 owner specification and the canonical shared-system contract. The owner specification and shared contract are requirements to satisfy; their text does not authorize overwriting shared contracts or P5-owned state. `NOT_STARTED` means no runtime evidence exists, `IN_PROGRESS` means only Phase 0 planning/contract mapping is underway, `BLOCKED` means a named external owner decision or integration is required, `PASS` is reserved for observed evidence, and `NOT_APPLICABLE` requires the stated scope reason.

**Baseline:** branch `feat/p2-feasibility-engine`; no backend/frontend skeleton or P2 runtime module existed at Phase 0 inspection. Paths below are planned P2-owned paths unless noted. Tests are not run in Phase 0 by explicit instruction. P5 migrations, shared contracts/auth/outbox/Core lifecycle, and P3 action execution are not P2-owned.
