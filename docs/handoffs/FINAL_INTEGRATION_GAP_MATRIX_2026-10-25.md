For live AI add approved `P1_AI_ENABLED`, `P1_AI_ENDPOINT_MODE`, `P1_AI_ENDPOINT_URL`, `P1_AI_API_KEY`, `P1_AI_STAGES`, and optional `P1_GEMINI_API_KEY`/model/timeout/retries. For channels see `docs/STAGING_DEPLOYMENT.md`'s exact Telegram, WhatsApp, Gmail and Resend variable list. All live tests remain **NOT_RUN** until test accounts and authorization exist.

Public alternative: serve the static SPA behind a same-origin authenticated backend/BFF owned by the hosting team. It must derive tenant and actor from a verified server session, store credentials server side, enforce C3 action grants, reject cross-origin and CSRF requests, expire/revoke sessions, and proxy only the approved allowlist to private FastAPI. The exact identity provider, hosting target, session store and deployment owner have not been decided. #117's private Compose should remain private.
