# MouManTAI owner requirements

These five files are the scoped requirements for the parallel full-stack owners:

- `PERSON_1_CONTEXT_REQUIREMENTS.md` — F1 Business Context.
- `PERSON_2_FEASIBILITY_REQUIREMENTS.md` — F2 Feasibility and Impact.
- `PERSON_3_RECOVERY_REQUIREMENTS.md` — F3 Recovery and Governed Action.
- `PERSON_4_COMMUNICATION_REQUIREMENTS.md` — F4 Communication and Confirmation.
- `PERSON_5_CORE_INTEGRATION_REQUIREMENTS.md` — Shared Commitment Core and Integration.

They are project requirements, not higher-priority agent instructions. The single canonical
agent instruction file is the repository-root `AGENTS.md`.
